# <img width="45" height="45" align="left" alt="ditda" src="https://github.com/user-attachments/assets/4956baca-58a7-41c7-8a91-bf30ff3c1dea" /> ditda Backend

> 학원을 위한 맞춤형 1:N 디자인 외주 매칭 서비스 **ditda**의 백엔드 레포지토리입니다. <br />
> 강사의 외주 등록부터 디자이너의 시안 제출·채택, 수정과 최종 확정까지 이어지는 매칭 플로우를 제공합니다.

> **💜 Service**: [ditda.kr](https://ditda.kr) · **📗 API Docs**: [Swagger](https://api.ditda.kr/swagger-ui.html)

<img width="1920" height="1080" alt="cover" src="https://github.com/user-attachments/assets/d4f6b553-17b1-470b-ac8c-2229a073ec59" />

## ✨ 주요 기능

- **외주 등록** — 강사가 플랜(디자이너 3~5명)을 고르고 컨셉·색상·참고 자료를 입력해 외주를 등록합니다.
- **디자이너 매칭** — 등급별로 1명씩 먼저 보장하고 남은 자리는 선착순으로 채웁니다. 자리가 모두 차면 마감 전에 바로 매칭됩니다.
- **시안 제출·선택** — 매칭된 디자이너들이 시안을 제출하면 워터마크가 자동으로 합성되고, 강사가 그중 하나를 고릅니다.
- **수정·최종 확정** — 강사가 기본 3회까지 수정을 요청한 뒤 최종 확정합니다.
- **마감 자동 처리** — 단계별 마감이 지나면 외주 상태를 넘기고, 인원 미달·미제출에 따른 환불과 디자이너 정산을 요청합니다.
- **정산·등급** — 디자이너는 기본금과 최종 선택 인센티브를 받고, 활동에 따라 경험치를 쌓아 등급이 오릅니다.
- **알림** — 진행 단계마다 강사·디자이너·어드민에게 안내 메일을 보냅니다.

## 📂 프로젝트 구조

```
src/main/java/ditda/backend
├── domain
│   ├── admin/              # 어드민 인증, 디자이너 계좌·포트폴리오 조회
│   ├── auth/               # 회원가입, 로그인, 리프레시 토큰
│   ├── commission/         # 핵심 도메인
│   │   ├── core/           # 외주 생성·조회, 마감 처리, 도메인 이벤트·알림
│   │   ├── application/    # 디자이너 지원
│   │   ├── draft/          # 시안 제출·조회
│   │   ├── revision/       # 수정 요청·응답
│   │   ├── watermark/      # 워터마크 처리·콜백·재시도
│   │   ├── dashboard/      # 강사·디자이너 대시보드
│   │   ├── history/        # 강사 외주 내역
│   │   └── category/       # 교재 등 카테고리별 상세 정보
│   ├── designer/           # 디자이너 프로필, 포트폴리오, 등급
│   ├── instructor/         # 강사 프로필
│   ├── payment/            # 결제, 환불 요청
│   ├── settlement/         # 정산
│   ├── term/               # 약관 동의 이력
│   └── user/               # 공통 사용자
└── global
    ├── apipayload/         # 공통 응답 포맷, 예외 처리
    ├── config/             # Security, Rabbit, Redis, Async, Swagger, Lambda
    ├── encryption/         # 암호화
    ├── hash/               # 리프레시 토큰 해시
    ├── image/              # 워터마크 이미지 합성
    ├── jwt/                # 토큰 발급·검증 필터
    ├── lock/               # 분산 락 AOP
    ├── logging/            # 로그 마스킹·정제, MDC 필터
    ├── monitoring/         # 비즈니스 영구 실패 메트릭
    ├── notification/       # Outbox 엔티티·스케줄러·RabbitMQ 발행
    └── s3/                 # Presigned URL, 파일 업로드·삭제
```
